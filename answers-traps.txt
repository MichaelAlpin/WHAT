1. Which registers contain arguments to functions? For example, which register holds 13 in main's call to printf?

The registers that contain the arguments to functions are a0, a1, a2, ..., a7 (or in our case, only a0, a1 and a2).
For example, a2 holds 13 in main's call to printf.
========================================================================================================================
2. Where is the call to function f in the assembly code for main? Where is the call to g?

Since the value of f(8)+1 is deterministic and isn't input depended, the compiler optimized the assembly by calculating
the value ahead instead of putting a call to <f>. Another optimization that the compiler made is putting the main code
of the one-liner function <g> - [addiw	a0,a0,3] - inside the function <f> that calls it -
that's why we don't have a call to <g> inside <f>.

6. In the following code, what is going to be printed after 'y='? Why does this happen?

After 'y=', the value of the register a2 (converted into decimal) is going to be printed.
This happens because the arguments that printf takes along the actual string are stored in a1, a2, ect, and because in our string we pass "x=%d y=%d"
but we only write 1 another argument, the assembly code of the program won't set a2 to anything, and the printf function will
print a2 as it is, hence why we will see the decimal value of what a2 was being printed.
